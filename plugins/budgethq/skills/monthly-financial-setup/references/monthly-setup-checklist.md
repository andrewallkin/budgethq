# Monthly Setup Reference Checklist

1. Create the new Monthly Money page using the established format.
2. Reset statuses and amounts; do not carry forward stale data.
3. Include a Complete column; mark Yes only when evidence supports it.
4. Confirm salary allocation and retained GoTyme amount. GoTyme to Daily = salary − GoalSaves due around the 21st − extra amount kept in GoTyme.
5. Reconcile Daily available balance to the R31,000 target. Excess above R31,000 can move toward Normal Savings. A shortfall is reported, not topped up from a guessed account.
6. Calculate consolidated transfer components and surplus exactly once.
7. Execute recurring costs via their workflow.
8. Execute the surplus transfer based on the already-calculated surplus.
9. Prepare month-end funding requirements for the following month.
10. Reconcile and report all completed, pending, failed, and uncertain items.
